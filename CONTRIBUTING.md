# Contributing to the Antigravity SDK Course

First off, thank you for considering contributing to this repository! It's people like you that make learning platforms such a great community to learn, inspire, and create.

## 🧠 How Can I Contribute?

### 1. Reporting Bugs
If you find a bug in any of the modules, please open an Issue. Include:
- Your operating system (e.g., Xubuntu 22.04).
- The exact error trace or log output.
- The module you were running (e.g., `04_streaming_pro`).
- Steps to reproduce the bug.

### 2. Suggesting Enhancements
If you have ideas for new modules, improved terminal UIs, or better ways to handle state memory:
- Open an Issue describing the enhancement.
- Explain why this enhancement would be useful to AI Agent Engineers learning the framework.

### 3. Submitting Pull Requests (PRs)
1. **Fork** the repository.
2. **Clone** your fork locally.
3. Create a **new branch** for your feature (`git checkout -b feature/amazing-feature`).
4. Commit your changes (`git commit -m 'Add amazing feature'`).
5. Push to the branch (`git push origin feature/amazing-feature`).
6. Open a **Pull Request** targeting the `main` branch.

## 📏 Coding Standards

- **Python Style**: We follow PEP 8. Please use clear, descriptive variable names.
- **Documentation**: If you add a new file or feature, make sure to document it. Each module should have a `README.md` and detailed `docs/`.
- **Modularity**: The overarching goal of this course is teaching *professional architecture*. Do not put all logic in one massive `main.py` file. Separate logic into controllers, managers, and agents.

Thank you for helping us build the best AI Agent Engineer curriculum on the internet!
